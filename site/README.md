# もっちり はむにぎり ｜ 特設サイト

「握って癒される虚無顔ハムスター」もっちり はむにぎり の、動きのある1ページ特設サイトです。
提供いただいた8枚のスクリーンショットの内容・キャッチコピー・写真をそのまま使って再現しています。

## 開き方

`index.html` をブラウザで開くだけで表示できます（ビルド不要・依存なし）。

```
site/
├── index.html      … サイト本体（HTML / CSS / JS すべて内包）
└── assets/         … スクリーンショットから切り出した商品写真（無加工）
```

## 内容（画像はそのまま）

- ONLINE SHOP バー ／ ヒーロー（もっちり はむにぎり・おもち/きなこ/みたらし/ごまきち）
- ハムの力でリラックス！（3つの吹き出し・3つの使いどころ）
- POINT 01〜08（ぬい撮り・持ち運び・後ろ姿・色合い・伸びる生地 ほか）
- はむにぎりに込めた思い
- 自分だけの可愛さを見つけよう！ ／ THANK YOU!

## 「動き」の仕掛け

- スクロールに合わせて各セクションがふわっと出現（IntersectionObserver）
- キャラクター・吹き出し・絵文字がぷかぷか浮遊＆ホバーでぷにっと変形
- ヒーローのキャラをタップ／クリックすると、ぷにっと潰れてハートが飛ぶ
- ナビ下のスクロール進捗バー、購入ボタンの鼓動アニメ、両脇を漂うマスコット
- ハムスターのイラスト（虚無顔・全身・絵文字）はすべて SVG で自作

> `prefers-reduced-motion` を有効にしている環境ではアニメーションを自動で抑制します。
